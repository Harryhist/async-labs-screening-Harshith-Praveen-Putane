## 🎯 The Campaign

### Campaign Concept: **"Calendar Clarity"**
- **Target Audience:** Product managers, CTOs, founders, busy C-suite professionals
- **Core Insight:** Calendar chaos is a real pain point. Executives waste 3+ hours/week managing meetings.
- **Solution:** A beautiful, always-on desk display that syncs with Google Calendar in real-time

## 🖌️ Design Choices

Beyond the base specs, I made a few additional aesthetic decisions while building out the static ad and carousel mockups:

- **Color palette:** Chose a dark navy-to-charcoal gradient (`#1a1a2e` → `#16213e`) as the base, paired with a teal/cyan accent (`#00d4ff`) for CTAs and highlights — meant to feel calm and trustworthy rather than alarming, even though the message ("Stop Missing Meetings") is pain-point driven.
- **Typography:** Used a clean sans-serif system font stack (SF Pro / Inter / Segoe UI style) for a modern, tech-forward feel that matches the product's minimalist hardware design.
- **Micro-interactions:** Added subtle hover states and a soft glow/shadow on the CTA button to make it feel clickable and premium without being flashy.
- **Carousel tone:** Leaned into a slightly more playful, emoji-forward visual language for the carousel (vs. the static ad) since carousels are consumed in a more casual, scroll-through context.
- **Visual consistency:** Kept the same accent color and button style across the static ad and carousel so the campaign reads as one cohesive identity, even across different formats.

These were personal creative calls on top of the required deliverables, aimed at making the campaign feel like a real, shippable brand rather than a generic mockup.

## 📊 Target Audience & A/B Test

### Audience Profile
- **Who:** Product managers, CTOs, founders, busy executives (25–50 yrs)
- **Where:** Remote/hybrid workers, high Slack + Calendar usage
- **Pain:** Meeting overlaps, context switching, cognitive overload
- **Income:** $80k–$250k+ (can afford a $400–500 productivity device)

### A/B Test Design
| Element | Control (A) | Test (B) | Hypothesis |
|---------|------------|---------|-----------|
| **Headline** | "Stop Missing Meetings" (pain-focused) | "Your Calendar, Impossible to Ignore" (empowerment) | Positive framing drives higher CTR |
| **Audience Segment** | All professionals | Executive + founders only | Niche targeting improves conversion |
| **Visual** | Busy desk | Minimalist desk | Clean aesthetic resonates better |

**Success metric:** Click-through rate (CTR); conversion rate if running to landing page
